# 🚀 HireNest – Internship & Fresher Hiring Platform

💼 A sleek internship platform UI built for students and recruiters — bridging talent with opportunity.

---

## 📌 Overview

HireNest is a modern front-end web application designed to simplify how students and freshers discover internships and entry-level jobs. It also provides a clean dashboard interface for companies to post and manage opportunities.

---

## ✨ Features

### 👨‍🎓 Student Side

* Browse internships and job listings
* Filter jobs by location, duration, and stipend
* Apply to roles with one click
* Track application status (Applied, Shortlisted, Selected, Rejected)
* Personal profile dashboard with skills, education, and experience

### 🏢 Company Side

* Post and manage internship listings
* View applicants and hiring stats
* Dashboard with key metrics

### 🤖 Smart UI Features

* AI-inspired skill gap analysis
* Job match percentage indicators
* Interactive modals and notifications
* Clean, modern, and responsive design
